¿Qué es DataVault?

Plataforma web donde equipos pueden crear sus propias bases de datos relacionales sin escribir SQL. Cada tabla define sus columnas en runtime, los datos se guardan en JSONB, y todo cambio queda en un audit log completo. Incluye colaboración en tiempo real, permisos granulares, scripts Python en la nube y deploy automático en AWS.

🗃️

Datos dinámicos

Columnas configurables en runtime. Sin ALTER TABLE. Sin redeploy.

👥

Multi-equipo

Workspaces con roles. Permisos por dataset, grupo o usuario.

⚡

Tiempo real

WebSocket con auth JWT. Cambios visibles al instante en todos los clientes.

🐍

Scripts Python

Ejecuta pandas / DuckDB / scikit-learn sobre tus datos en AWS Lambda.

📋

Audit log

Historial completo de quién cambió qué, cuándo y desde qué dataset.

Deploy automático

Token JWT incluye el rol global embebido. Sin sesiones en servidor. WebSocket autentica enviando el token como primer mensaje (no en query string).

Jerarquía de permisos por dataset

🔑 ¿Es admin global?
✅ Sí → Acceso total (admin)
No ↓
🏢 ¿El dataset pertenece a un workspace del que es miembro?
✅ Sí → Usa rol del workspace mapeado (owner→admin · admin_ws→editor · member→editor)
No ↓
📋 ¿Tiene permiso directo en este dataset?
✅ Sí → Usa ese rol asignado
No ↓
👥 ¿Pertenece a un grupo con permiso en este dataset?
✅ Sí → Mejor rol entre sus grupos
No ↓
🌐 Usa su rol global (viewer / editor)

Features implementadas

🗃️ Core — Datasets y Registros

  • Datasets con columnas configurables en runtime
  • CRUD de registros inline (edición en celda)
  • Soft delete + papelera + restore
  • Importar CSV / Excel (multipart)
  • Exportar CSV (UTF-8 BOM) y Excel SpreadsheetML
  • Joins automáticos entre tablas por field_key
  • Vista tabla editable, kanban, gráficos
  • Drag & drop de columnas
  • Pegar TSV desde Excel/Sheets (Ctrl+V)
  • Búsqueda full-text con índice GIN

👥 Colaboración y Organización

  • Workspaces con roles owner/admin/member
  • WorkspaceSwitcher con avatares en la UI
  • Grupos de usuarios con permisos por dataset
  • Sincronización en tiempo real vía WebSocket
  • Audit log con filtros multi-persona, workspace, dataset
  • Rate limiting: 10/min en login, 5/min en registro
  • Admin panel: usuarios, grupos, workspaces, audit
  • effective_role considera workspace — miembros ven y editan según su rol en el workspace
  • Botones de edición visibles correctamente según rol efectivo en DatasetView

🐍 Scripts Python (Computed Datasets)

  • Editor Monaco, tema oscuro, 620px
  • Sidebar: datasets fuente + chips de columnas
  • Botón "Generar plantilla" con columnas reales
  • Ejecuta en AWS Lambda — timeout 15 min
  • Re-ejecutar reemplaza solo ese computed dataset

🔗 Relaciones N:N unificadas (modelo Airtable-style)

  • Todas las columnas relation guardan arrays JSONB (1 valor = 1:N · N valores = N:N)
  • Auto-migración escalar → array al cambiar a data_type=relation
  • Editor multi-chip con autocomplete server-side (debounce 220ms)
  • Scanner avanzado: nombre + contenido (tilde/case-insensitive)
  • Detección de tablas puente y conexiones N:N automáticas
  • Tabla intermedia opcional (is_bridge=true) solo cuando hay atributos del vínculo
  • Wizard "Crear N:N" auto-genera bridge con 2 FKs
  • Joins via bridge: lookup 2-step transparente en DataGrid
  • Cleanup suggestions: detecta variantes "Comercio/COMERCIO/comercio" y unifica
  • Diagrama SVG con cardinalidad N↔N, grilla cuando no hay relaciones, datasets aislados separados

🔐 Sistema de permisos avanzado

  • 4 roles: admin / editor / viewer / none (bloqueo explícito)
  • Prioridad: admin global > directo > grupo > workspace
  • Bloqueo "none" directo overrides cualquier grupo o workspace
  • effective_role automático en todos los endpoints
  • Matriz invertida: ver datasets accesibles por grupo/usuario
  • Admin consolidado en 2 páginas: /admin/personas (Personas y accesos) + /admin/workspaces (equipos)
  • Matriz de accesos editable: elegí grupo → control segmentado por dataset (Sin acceso · Ver · Editar · Admin), un click, guardado optimista
  • Endpoint batch /workspaces/{id}/access-matrix (toda la matriz en 1 request, sin N+1)
  • Origen del permiso visible: direct / group:X / workspace:rol / global_admin
  • Audit log de cambios de permisos con timestamps
