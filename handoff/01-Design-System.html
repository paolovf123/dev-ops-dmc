Reglas de uso
  • Siempre desde la escala. Si necesitas un tamaño intermedio, primero replantea el layout — casi nunca es la solución.
  • Tabular nums obligatorio en columnas numéricas: font-variant-numeric: tabular-nums.
  • Mono solo para datos máquina: RUC, IDs, fechas ISO, montos en chips, código. Nunca para titulares de UI.
  • Letter-spacing negativo en H1/H2/H3 (−2 a −2.5%) para que respiren a tamaños grandes.

Fundamento · Radios

Suave y cálido

Radios entre 8 y 16 px — lo suficiente para que la interfaz se sienta moderna y amigable, sin caer en lo infantil. Stripe es muy cuadrado; nosotros un punto más cálido tipo Vercel.

--r-14 px · inputs sm, badges
--r-28 px · botones, chips, inputs
--r-312 px · cards, modales sm
--r-416 px · cards grandes, modales
--r-524 px · contenedores hero
--r-pill999 px · chips, avatares
Fundamento · Sombras

4 elevaciones

Sombras tintadas hacia tinta (no negro puro) y de baja saturación. La diferencia entre niveles es sutil — el sistema usa principalmente 1 y 2; 3 para flotantes y 4 solo para modales y popovers altos.

--shadow-1card hover, input
--shadow-2card flotante, toolbar
--shadow-3toast, hover-card
--shadow-4modal, command palette
Fundamento · Iconografía

Lucide · 16 px default

Línea fina y geométrica. Tamaño base 16 px en UI, 14 px dentro de botones, 18 px en sidebar y page headers. Stroke 1.75 uniforme. Nada de emojis fuera de el menu de Tab opcional.
